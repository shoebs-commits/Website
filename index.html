ABOUT THE PROJECT

Meet PDFKit

PDFKit is a web-based PDF conversion and management system designed to make common document operations simple and accessible. It provides image-to-PDF conversion, PDF merging, and page extraction through a clean and responsive interface.

The application uses a Python FastAPI backend, SQLite for operation history, Pillow for image processing, and pypdf for PDF manipulation.
